# Paradise Nursery

Paradise Nursery is a React houseplant shopping application built for the Coursera final project. Browse 18 houseplants across three categories, add plants to a Redux-powered cart, adjust quantities, remove items, and review totals before checkout.

## Run locally

```bash
npm install
npm run dev
```

The project uses React, Vite, Redux Toolkit, and React Redux. The landing page, product listing page, and shopping cart page are implemented in the existing `src` component structure.
