# Paradise Nursery

Repository: e-plantShopping

Paradise Nursery is a React-based houseplant shopping application created for the Coursera final project. This repository, e-plantShopping, includes a landing page, plant catalog, and shopping cart experience for browsing houseplants, adding items to the cart, updating quantities, removing products, and reviewing totals before checkout.

The app features a welcoming Paradise Nursery homepage, product categories, a Redux-powered shopping cart, and a user-friendly shopping experience for plant lovers.

## Features

- Landing page with company welcome message and Get Started button
- Product listing with 18 plants across 3 categories
- Add to Cart functionality with cart count updates
- Shopping cart with quantity controls, total cost, and remove actions
- Responsive design using React and Vite

## Run locally

```bash
npm install
npm run dev
```

The project uses React, Vite, Redux Toolkit, and React Redux. The landing page, product listing page, and shopping cart page are implemented in the `src` component structure.
